Decisions the user did not ask for, with why:
- a 5-minute TTL: long enough to take load off the database, short enough for price changes to show soon,
- the cache lives in process memory (a module-level Map): no new infrastructure,
- no invalidation when a price changes: the TTL bounds how stale a price gets,

- the service runs as several instances behind a load balancer; each has its own cache.
